# Negaresh Yar V1 - Product Specification

## Overview

Negaresh Yar V1 is a lightweight online service platform for administrative writing, legal document drafting, online internet services, and AI-powered judicial document interpretation.

The goal of V1 is to launch a simple, professional, and production-ready product without unnecessary complexity.

---

# Product Goals

The main goals are:

- Provide fast access to writing services.
- Allow users to understand judicial documents using AI.
- Generate SEO-friendly content through an AI-assisted workflow.
- Provide simple management tools for the website owner.

---

# Target Users

## User Type 1: Document Interpretation User

Needs:

- Understand a court decision.
- Receive a simple explanation.
- Contact Negaresh Yar if further help is needed.

Flow:

Visit website → Upload document → Receive AI explanation → Contact service provider


---

## User Type 2: Writing Service User

Needs:

- Administrative letters.
- Legal text preparation.
- Online services.

Flow:

Visit website → Choose service → Contact through messenger


---

## User Type 3: Search Engine Visitor

Needs:

- Find legal and administrative information.
- Read helpful articles.

Flow:

Google → Article → Learn → Contact Negaresh Yar


---

# Core Features

## 1. AI Judicial Document Interpreter

Description:

A user can upload a judicial document and receive a simplified explanation generated by Google Gemini.

Supported files:

- PDF
- JPG
- PNG


Important Notice:

The AI interpretation may contain mistakes or inaccurate analysis.

The result is only for easier understanding and is not a replacement for professional legal advice.


---

## 2. Request Contact Page

Purpose:

Provide a simple communication channel without user accounts.

Supported platforms:

- WhatsApp
- Telegram
- Eitaa
- Rubika
- Bale


Features:

- Official platform icons.
- Editable links from admin panel.
- One-click messaging.


---

## 3. AI Article System

Purpose:

Create high-quality SEO articles.

Workflow:

Topic → Research → Writing → Review → Scoring → Publishing


Publishing rule:

Only articles with final score >= 80 can be published.


---

## 4. Invoice Generator

Purpose:

Generate simple branded invoices.

Features:

- Create invoice.
- Add service items.
- Generate PDF.
- Use Negaresh Yar logo.


---

# Excluded Features

The following features are NOT part of V1:

- User registration
- User login
- Customer accounts
- Customer management
- Case management
- Internal chat
- Ticket system
- Online payment
- Complex CRM


---

# Product Principles

1. Keep the product simple.
2. Avoid unnecessary features.
3. Prioritize mobile users.
4. Optimize for speed and usability.
5. Build a strong foundation for future versions.
