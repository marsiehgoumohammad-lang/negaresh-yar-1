# Negaresh Yar V1 - Project Specification

## Project Name

نگارش یار

## Brand Description

نگارش یار:
نگارش نامه اداری، عریضه نویسی، کافی نت آنلاین

---

# Project Goal

نگارش یار V1 یک سرویس آنلاین ساده و سریع برای ارائه خدمات:

- نگارش نامه های اداری
- عریضه نویسی
- خدمات کافی نت آنلاین
- تفسیر ساده اوراق و آرای قضایی با هوش مصنوعی

است.

---

# V1 Philosophy

هدف نسخه اول:

ساخت یک محصول کوچک، حرفه ای و قابل استفاده.

این نسخه نباید تبدیل به یک سیستم پیچیده شود.

---

# Core Features

## 1. AI Judicial Document Interpretation

کاربر می‌تواند فایل رأی یا سند قضایی خود را ارسال کند.

سیستم با Google Gemini:

- متن را تحلیل می‌کند.
- مفهوم آن را ساده‌سازی می‌کند.
- نتیجه را نمایش می‌دهد.

---

## 2. Request Contact System

کاربر بدون ثبت نام و ورود:

از طریق پیام رسان‌ها با نگارش یار ارتباط می‌گیرد.

Supported platforms:

- WhatsApp
- Telegram
- Eitaa
- Rubika
- Bale

---

## 3. AI Article System

پنل مدیریت شامل:

- تولید مقاله
- بررسی کیفیت
- امتیازدهی
- انتشار مقالات سئو شده

---

## 4. Invoice Generator

سیستم ساده صدور فاکتور با لوگوی نگارش یار.

---

# Explicitly Excluded Features

در V1 وجود ندارند:

- User Registration
- User Login
- Customer Panel
- Case Management
- Internal Chat
- Ticket System
- Complex CRM
- Online Payment

---

# Design Philosophy

نگارش یار باید:

- ساده
- سریع
- قابل اعتماد
- حرفه ای

باشد.

---

# Main UX Rule

Mobile First

نسخه موبایل مرجع اصلی طراحی است.

Desktop و Tablet از روی نسخه موبایل توسعه پیدا می‌کنند.

---

# Development Rule

هیچ قابلیت جدیدی بدون تصمیم معماری اضافه نمی‌شود.

Build فقط مجری دستورات است.
