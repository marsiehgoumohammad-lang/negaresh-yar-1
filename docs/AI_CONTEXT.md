# Development Approach

This project follows a documentation-first development process.

All decisions are defined inside the docs folder.

The implementation agent must read and follow these documents.


---

# Main Technology

Backend:

Laravel


Frontend:

Blade + Tailwind CSS + JavaScript


AI:

Google Gemini API


---

# Main Principle

Build the smallest professional version first.

Avoid unnecessary complexity.


---

# Design Principle

Mobile First.

Most users access the website through mobile devices.

All pages must prioritize mobile experience.


---

# Important Restrictions

Do not create:

- User registration
- User login for customers
- Customer panel
- Case management
- Internal chat
- CRM features


---

# AI Warning Requirement

Any AI-generated interpretation must clearly mention:

The result is generated by artificial intelligence and may contain errors. It is not a replacement for professional legal advice.


---

# Implementation Behavior

The AI coding agent must:

- Follow instructions.
- Read documentation.
- Avoid independent decisions.
- Avoid adding features.
- Report completed work.
