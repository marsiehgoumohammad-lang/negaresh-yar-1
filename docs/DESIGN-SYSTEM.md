# Negaresh Yar V1 Design System

## Main Principle

The entire project follows Mobile First design.

Mobile layout is the primary design source.

Desktop and tablet are adaptations.

---

# Design Feel

The interface must communicate:

- Trust
- Simplicity
- Professionalism
- Modern technology

Avoid:

- Government website style
- Old internet cafe style
- Generic AI style

---

# Typography

Use the same Persian fonts defined in the original Negaresh Yar project.

Do not introduce new fonts.

Typography rules:

- Clear headings
- Readable body text
- Comfortable line height

---

# Colors

Maximum three main colors.

Required feeling:

- Professional
- Trustworthy
- Clean

Avoid:

- Neon colors
- Heavy gradients
- Artificial AI visual styles

---

# Buttons

Only three button types:

## Primary Button

For main actions.

Examples:

- Start AI Interpretation
- Submit Request


## Secondary Button

For secondary actions.


## Text Button

For simple navigation.

---

# Cards

Cards are used only when needed.

Rules:

- Soft corners
- Minimal shadow
- Clean spacing

---

# Icons

Use consistent icon style.

Official brand icons must be used for:

- WhatsApp
- Telegram
- Eitaa
- Rubika
- Bale

---

# Animation

Use only professional lightweight animations.

Allowed:

- Fade
- Smooth transition
- Loading states

Avoid:

- Heavy animations
- Decorative motion

---

# Quality Rules

Every page must:

- Work perfectly on mobile
- Have clear purpose
- Have one main CTA
- Follow this design system
