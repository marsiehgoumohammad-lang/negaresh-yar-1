# Negaresh Yar V1 - SEO Specification

## Purpose

This document defines the SEO strategy and technical SEO requirements for Negaresh Yar V1.

SEO is a core part of the product, not a final optimization step.

The website must be built from the beginning with search engine visibility in mind.

---

# SEO Goals

Main goals:

- Rank for administrative writing services.
- Rank for legal document writing searches.
- Attract users searching for judicial document explanations.
- Build organic traffic through helpful articles.

---

# SEO Strategy

Negaresh Yar follows a content-driven SEO strategy.

The main traffic sources:

1. Service pages
2. Educational articles
3. AI judicial interpretation feature
4. Google search results

---

# Technical SEO Requirements

## 1. Clean URLs

All URLs must be readable and meaningful.

Examples:

Correct:
/articles/how-to-write-official-letter


Incorrect:


/page?id=123

---

# URL Rules

URLs must:

- Be short.
- Use meaningful words.
- Avoid unnecessary parameters.
- Be SEO friendly.

---

# 2. Meta Tags

Every important page must have:

- Title tag
- Meta description
- Canonical URL
- Open Graph tags


---

# Homepage SEO

Required:

Title:

Negaresh Yar | Administrative Writing, Legal Documents and Online Services


Description:

Professional online services for administrative writing, legal document drafting, and AI-powered judicial document interpretation.


---

# Article SEO

Every article must include:

- SEO title
- Meta description
- Slug
- Main keyword
- Featured image
- Structured headings


---

# 3. Sitemap

The website must provide:
/sitemap.xml


The sitemap must include:

- Homepage
- Public pages
- Published articles


Draft articles must not appear.


---

# 4. Robots.txt

The website must provide:


/robots.txt


Rules:

Allow:

- Public pages
- Articles


Disallow:

- Admin panel
- Private paths


Example:


Disallow: /admin


---

# 5. Schema Markup

Required Schema types:

## Organization Schema

For brand information.


## Article Schema

For blog articles.


## WebSite Schema

For website identity.


## FAQ Schema

Only when FAQ content exists.


---

# 6. Internal Linking

Articles must support internal links.

Goals:

- Help users discover related content.
- Help Google understand website structure.


Examples:

Article about official letters:

Link to:

- Writing services page.
- Request page.
- Related articles.

---

# 7. Content SEO Rules

Articles must:

- Answer real user questions.
- Be written naturally.
- Avoid keyword stuffing.
- Provide practical value.

---

# Article Quality System

Before publishing:

The article must be reviewed by AI agents.

Required final score:

>= 80


Scores:

- SEO Score
- Content Score
- Quality Score


---

# 8. Google Search Console Integration

V1 requirements:

The system should be prepared for Google Search Console connection.

Required abilities:

- Monitor indexing status.
- Detect basic search performance data.
- Support URL indexing workflow.


Advanced automation is not required in V1.

---

# 9. Performance SEO

Required:

- Optimized images.
- Lazy loading.
- Fast page loading.
- Minimal JavaScript.
- Clean HTML structure.


---

# 10. Mobile SEO

Because most users are mobile users:

The website must:

- Be responsive.
- Have readable text.
- Have large touch targets.
- Load quickly on mobile networks.


---

# SEO Restrictions

Do not use:

- Artificial keyword stuffing.
- Duplicate content.
- Automatically generated low-quality pages.
- Hidden SEO text.


---

# SEO Development Rule

SEO must be implemented during development.

Do not postpone SEO until after launch.
